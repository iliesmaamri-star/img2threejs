# دفتر حسابات الورشات

تطبيق صفحة واحدة لمتابعة مداخيل ومصاريف مقاولة بناء حسب كل زبون ومشروع.

النسخة المنشورة: https://claude.ai/artifact/Vdd6VeswkeTBhqzdo46cgm

## ما يفعله

- **الزبائن والمشاريع**: قيمة العقد، الدفعات المقبوضة، المصاريف، الرصيد، والمبلغ المتبقي على الزبون، مع كشف حساب بالرصيد بعد كل عملية.
- **ثلاثة أنواع من العمليات**: دخل أو دفعة من زبون، مصروف لمشروع أو للمكتب، وتحويل داخلي بين الأعضاء.
- **الفواتير**: تصوير الفاتورة بالهاتف أو رفع صورة أو PDF، وتُضغط الصور تلقائيا قبل الرفع.
- **التاريخ والساعة**: لكل عملية تاريخ وساعة العملية، ووقت التسجيل الفعلي، ومن سجّلها.
- **سجل لا يُمحى**: التعديل يحفظ القيم السابقة، والإلغاء يتطلب سببا ويبقى ظاهرا في السجل بدل الحذف.
- **أين توجد الأموال**: رصيد كل شريك أو عضو أو صندوق حسب من استلم ومن دفع.
- **الأرباح**: صافي المشاريع المنتهية ناقص مصاريف المكتب، موزّع حسب نسبة كل شريك وما سحبه.
- **تصدير CSV** يُفتح في Excel.

## التقنية

ملف HTML واحد بدون مكتبات. يعتمد على قدرات صفحات Claude: `db` لتخزين البيانات المشتركة، `assets` لصور الفواتير،
`user` لمعرفة من سجّل العملية، و`downloads` للتصدير. خارج claude.ai تظهر الصفحة بدون تخزين.
